# 每月固定动作 SOP

> 下面的清单可以直接勾选，进度按月份保存在本机浏览器里。
> 每月 1 号会自动切到新的一个月，上月的勾选记录保留。

## 一、月初（1–5 日）｜工资准备

- [ ] 收集本月工资数据，做出各公司工资表（口径见 `03.工资/工资计算规则.md`）
- [ ] 「工资管理 → 新建工资批次」，选公司和工资所属月份
- [ ] 进批次详情「导入工资表」，上传 xlsx
- [ ] 检查「缺银行账号」卡片是不是 0；有缺的去「基础资料 → 员工」补卡号后重新导入
- [ ] 核对应发/实发合计与工资表一致
- [ ] 点「生成付款单（按批次）」——按单文件 5 万自动拆批，一批一张付款单

## 二、发薪日（10 日前后）

- [ ] 「工资管理 → 批次详情」逐批下载银行模板（.xls，农行代发格式）
- [ ] 网银上传代发文件，完成发放
- [ ] 回到「付款管理」：提交审批 → 管理者审批 → **标记已付款**（这一步才生成流水）
- [ ] 标记付款时选对**付款账户**，钱从哪个账户出就选哪个

> ⚠️ 这里最容易错：付款单挂错公司或账户，钱就记到别家账上去了。
> 生成付款单前先确认工资批次的公司选对了。

## 三、月中｜日常

- [ ] **收到客户回款**：「应收与收款 → 登记应收款」，勾上「已收到款」并选收款账户
- [ ] **还没到账的合同款**：同样入口，不勾「已收到款」，填预计收款日，到账后再点行末「登记回款」
- [ ] **报销**：员工提交 → 财务审批通过 → 勾选多笔「生成付款单」（同一人自动合并）→ 走付款流程
- [ ] **发票**：收到的进项票、开出的销项票录入「发票台账」，或用 Excel 批量导入
- [ ] **供应商/房租/税费等待付事项**：先在「应付台账」登记，付的时候用行内「快速付款」选账户付掉
- [ ] **其他杂项收支**（利息、手续费、退款）：直接走「资金流水 → 新增流水」，那里必填账户
- [ ] **想少点几下**：以上应收 / 发票 / 流水 / 新账户，都可以打开右上角「录入助手」说一句话出草稿，**在哪个页面都行，一句话也可以说几件事**，
  先在列表行上点「@」引用相关的客户、账户或记录；收到钱时 @ 发票或应收说「这笔钱收到了」，提交后会冲减应收；**草稿只是建议，核对每个字段后再点「确认提交」或「填入表单」保存**；
  提交后卡片显示「已提交 · 编号 XXX」，**不用担心点两次会记两笔**（提示「这笔刚才已提交过」就是没有重复记账）

## 四、月末 / 次月初｜导流水 + 对账（**最关键**）

- [ ] 从各家网银导出上月对账单，**优先选 Excel / CSV**，存到 `02.流水账/<公司>/`
- [ ] 「资金 → 导入银行流水」，一家一家导：选公司 → 选账户 → 传文件
- [ ] 表头认不出来时，用预览页的「手工指定列」选出日期列、金额列，再重新解析
- [ ] 检查预览页三件事：
  - [ ] 红色提醒：有没有早于期初基准日的流水（有就用日期过滤排除）
  - [ ] **疑似重复**：工资、回款这些你已经在系统里记过的，会被标出来，默认跳过——别关掉这个开关
  - [ ] 业务类型猜得对不对，不对就在预览页直接改，或导入后批量改
- [ ] 导完跑一次对账脚本：

```bash
cd ~/Develop/gitee/yihu-finance/backend && node scripts/reconcile-check.mjs
```

- [ ] 确认四家账户差异都是 **0.00**；不为 0 看脚本列出的「系统有银行没有」「银行有系统没有」，逐笔查
- [ ] 「资金流水」页面全选本月流水，批量标记为**已核对**

## 五、月结

- [ ] 「分析与月结 → 月结工作台」，逐家公司选上个月
- [ ] 八项检查逐条看，没过的去对应模块处理
- [ ] 全过之后点「锁定」——锁定后该月流水和付款不能再改
- [ ] 复制右侧 Markdown 月结摘要，贴回 `02.流水账/<公司>/YYYY-MM.md` 归档
- [ ] 看一眼「异常清单」，把缺账号、重复发票、逾期收付款处理掉

## 六、季度 / 不定期

- [ ] 「资金预测」：更新固定周期支出（房租、社保、云服务），让 30/60/90 天预测准
- [ ] 「基础资料 → 项目」：从 FDE 平台同步客户和项目

```bash
cd ~/Develop/gitee/yihu-finance/backend && npm run sync:fde
```

- [ ] 备份数据库

```bash
mysqldump -uroot -proot yihu_finance > ~/backup/yihu_finance-$(date +%Y%m%d).sql
```
