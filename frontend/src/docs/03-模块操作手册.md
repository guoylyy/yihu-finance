# 模块操作手册

## 账户管理

- **新增账户**：所属公司、名称、类型、币种、期初余额、**期初基准日**
- **对账**：行末「对账」看账面余额 vs 流水推算余额，差异应恒为 0
- **内部转账**：一次生成两条互指的流水（转出账户支出、转入账户收入），两边余额同时更新；跨公司转账会记成「公司间往来」
- 账号对非授权角色自动脱敏，只显示后四位

## 资金流水

系统的核心事实表，所有收付款最终都落到这里。

- 支持按公司、账户、收支方向、业务类型、状态、日期、金额区间、关键字筛选，筛选结果带合计
- **批量操作**：勾选多行后可批量改业务类型、分类、状态
- **状态**：待核对 → 已核对；异常的标「异常」，月结会拦
- 导出 Excel 带当前筛选条件
- 已月结锁定的月份，流水不可增删改

## 导入银行流水

- 支持 CSV / XLS / XLSX，UTF-8 和 GBK 自动识别
- 常见网银格式自动认表头；**认不出就用「手工指定列」**，前 8 行样例摊开给你选哪列是什么
- 「收支方向」三种：按金额正负 / 全部算收入 / 全部算支出（只有收款明细的导出用得上）
- **查重两层**：
  - *完全重复* — 同账户同日同额同对方同摘要，之前导过
  - *疑似重复* — 同账户同日同额同方向但文字对不上，多半是你手工记过（比如工资走付款流程记的）
  - 两个跳过开关默认都开着
- 流水金额和待付/已付的付款单对得上时，会标出对应单号
- 业务类型自动猜：认识员工姓名（判工资/劳务费）、认银行规费、认税费社保

## 应收与收款

- **已经收到的钱**：新增时勾「已收到款」+ 选收款账户 → 一步到位，自动生成收入流水
- **还没到账**：不勾，填预计收款日和把握度；到账后点行末「登记回款」
- 把握度影响资金预测：只有「已确认」才计入保守预测口径
- 逾期未收会在驾驶舱和异常清单里报出来

## 应付台账

记"该付谁多少钱"：供应商欠款、房租、税费等各类待付事项。

- **快速付款**（行末按钮）是日常最常用的入口：选账户 → 确认金额 → 付掉。
  - *直接记已付款*：钱已经付出去了，立刻生成支出流水、扣账户余额、回写应付状态
  - *生成付款单送审*：还没付，生成待审批的付款单，后续在付款管理走流程
  - 金额默认带出未付余额，改小即为部分付款，付到一半状态是「部分付款」
- 直接付款需要同时有审批和付款权限；只有财务权限的账号只能送审
- 「付款记录」看这笔应付分几次付的、每次关联哪条流水

> 用快速付款就不用再去付款管理新建单子、手工关联了。
> 只有工资、报销这类有上游单据的付款才从各自模块生成。

## 付款管理

状态流转：`草稿 → 待审批 → 待付款 → 已付款 → 已核对`

- 工资、报销生成的付款单都是**草稿**状态，要手工提交审批
- 审批需要管理者权限；批量审批可多选
- **标记已付款**时才生成支出流水并扣减账户余额
- 银行先付了、单子后补的场景：用「关联流水」把付款单和已导入的流水挂上
- **作废付款单会连带作废它生成的流水**，余额自动回退

## 工资管理

- 支持工资表和劳务费表两种格式，按姓名匹配员工档案自动补银行卡号
- 缺卡号的会单独列出来，补完重新导入
- **银行模板按单文件 5 万拆批**，一批一个文件，与网银上传一一对应
- 生成付款单两种模式：按批次（一批一单，对账方便）/ 一人一单（逐笔审批）

## 报销管理

提交 → 审批 → 生成付款单 → 付款回写状态。同一人多笔报销生成付款单时会自动合并成一张。

## 发票台账

- 销项 / 进项 / 费用 / 红字四类
- 金额、税额、价税合计填两个，第三个自动补
- **查重**按公司内发票号，重复的会在月结检查里拦下
- 可与流水关联，关联后状态变「已入账」

## 借贷与往来

公司借给个人 / 个人借给公司 / 公司间拆借 / 代付垫款四种方向。登记还款时可同时生成流水，未还余额自动算。

没走公司账户的个人垫付，**不要记成银行流水**，记到这里。

## 月结工作台

八项检查：余额是否更新、流水是否导入、是否全部核对、有无异常流水、工资是否关联付款、报销是否结清、发票有无重复、有无逾期收付款。

全过后可锁定月份；锁定后该月流水和付款不可修改，需管理员填原因解锁（记审计日志）。右侧生成 Markdown 月结摘要，可直接贴回 Obsidian 账本。

## 资金预测

```
预计期末余额 ＝ 当前可用余额 ＋ 预计收款 − 已审批待付款 − 固定周期支出
```

30 / 60 / 90 天三个窗口 + 逐日余额曲线。**固定周期支出**（房租、社保、云服务）要自己维护，维护得越全预测越准。
