# 更新日志

> 每次系统改动都记在这里，方便回头查"这个功能什么时候有的""行为怎么变了"。

## 2026-09-29

**可以部署到以虎 One 平台**

- 作为应用插到以虎 One 上：用平台统一登录（不用再记本系统密码），地址是 `<平台地址>/apps/finance/`
- 第一次从平台进来时按用户名对上原来的账号；没有账号的自动建成「业务 STAFF」，由管理员在「用户管理」里调角色
- 在平台上默认关闭账号密码登录；退出后回到平台工作台
- 平台 AI 助手可以直接问：现在账上有多少钱、未来 30 天够不够用、有哪些逾期和异常、某家公司的月报（只读，不能付款、改账）
- 本地开发照旧，没有任何变化

## 2026-09-12

**修复上传文件名乱码**

- 中文文件名经 multer 上传后变成 `ä»¥è...` 这种乱码（multipart 字段按 latin1 解析所致），
  导入批次、操作日志里存的都是乱码
- 流水导入、工资表导入、发票导入、附件上传统一做编码还原；历史数据一次性修好
  （5 条导入批次 + 14 条操作日志）

**应付台账支持快速付款**

- 应付台账行内新增「快速付款」：直接选账户付掉，不用再去付款管理重录一遍、手工关联
- 两种处理方式：*直接记已付款*（立刻生成流水、扣余额、回写应付状态）/ *生成付款单送审*（走正常审批流）
- 支持部分付款，金额默认带出未付余额，超额会被拦下
- 直接付款需要同时具备审批与付款权限；财务角色只能送审，权限隔离没被绕开
- 新增「付款记录」弹窗，看这笔应付款分几次付的、各自关联哪条流水
- 付款执行逻辑抽成 `lib/payment.js`，付款管理与快速付款共用同一套

**四家账户对账全部归零**

- 期初余额一律改按银行对账单口径校准，账户新增「期初基准日」字段
- 作废与银行逐笔明细重复的汇总口径种子流水（云帆 3 笔、星野 2 笔、拾光云 1 笔）
- 拾光云 3,616 个人垫付从银行流水移出，转为借贷台账 `LN-2026-0001`
- 发现并修正拾光云账本余额错误（884,258.00 → 实际 384,258.43）
- 新增对账脚本 `scripts/reconcile-check.mjs`，逐笔比对系统与对账单
- **修复**：作废付款单现在会连带作废它生成的流水并重算余额

**银行流水导入增强**

- 支持无表头文件：按数据形态推断列，并提供「手工指定列」面板（前 8 行样例 + 逐字段选列）
- 收支方向支持「按金额正负 / 全部收入 / 全部支出」
- 修复农行导出末尾汇总行被解析成 2001 年假流水
- 修复列名错配：单列金额不再落到「收入金额/借方」上，工行 36 列对账单的摘要与收付方名称能正确识别
- 新增「疑似重复」识别（同账户同日同额同方向），默认跳过
- 流水金额与待付/已付付款单对上时标出对应单号
- 业务类型识别认员工姓名（判工资/劳务费）、认银行规费与税费社保
- 预览页新增日期范围过滤 + 早于期初基准日的红色提醒

- 后端 Express 4 + Prisma 6 + MySQL 8，前端 Vue 3 + Element Plus + ECharts
