# 更新日志

> 每次系统改动都记在这里，方便回头查"这个功能什么时候有的""行为怎么变了"。

## 2026-10-30（右上角显示版本号）

**报问题时能说清是哪个版本了**

- 新功能：电脑上顶栏头像左侧显示当前版本（如 `v1.3.1`）；手机上不占顶栏，点头像，下拉第一行就是「版本 v1.3.1」
- 接口：`/api/health` 多返回 `version`，取自 `yh-app.json`，发版时改这个文件即可，界面自动跟着变

## 2026-10-29（v1.3.1 · 录入助手跨页面操作）

**录入助手不再被当前页面限制：在哪个页面都能录，做什么听你说的**

- 新功能：四类草稿（账户 / 应收 / 发票 / 流水）在**任何页面**都能生成。比如在账户页 @ 一个账户说「给这个账户记一笔收款 5000」，出来的是流水草稿；在基础资料页也能说「给客户 X 建一笔应收 2000」
- 新功能：**一句话可以说几件事**。「记一笔收款 1000，再开一张 1000 的发票」出两张草稿；「记两笔收款，1000 和 2000」也是两张
- 新功能：**回款**。@ 一张发票或应收说「这笔钱收到了」，生成回款草稿：确认提交后会冲减对应应收、生成销售回款流水并关联发票（和点「登记回款」一样）。
  发票和应收没有直接关联，系统按「同客户、未收清、金额相等且只有一笔」匹配；匹配不上就列出来让你选，或提示「不会冲减应收」，不会猜
- 变化：草稿卡加了类型徽章（账户 / 应收 / 发票 / 流水 / 回款）；「填入表单」发现草稿不是当前页的类型，会自动跳到对应页面并打开预填好的弹窗（回款草稿打开登记回款弹窗）
- 变化：切换页面时助手抽屉不关，对话、草稿和 @ 引用都保留，可以连续跨页操作
- 变化：助手确定信息的顺序：你明确说的 > 你 @ 的 > 页面筛选条件 > 都不确定就问，不猜
- 变化：基础资料页的客户、供应商也能点「@」引用了
- 变化（权限）：**@ 了不存在或无权访问的记录，这句话会被整句拒绝**，提示「引用的记录不存在或无权访问」，把那条 @ 移除后重试。以前是悄悄忽略这条引用继续生成，「这个账户」可能落到别的引用上
- 修复：一次生成两张同类型的新草稿时，后一张会把前一张覆盖掉
- 修复（权限）：通过接口新增流水时，可以挂上别家公司的发票；现在提示「发票不属于该公司」
- 接口：`/assistant/status` 多返回 `draftKinds`；说明见 `docs/接口说明.md`

## 2026-10-29（v1.3.0 · 重复入账、撞号、数据范围补漏）

**录入助手「确认提交」不会再记两笔；多人同时录入不会再报错**

- 修复：录入助手的同一张草稿连点两次「确认提交」，会生成两张应收 / 两笔流水（余额扣两次）。现在第二次直接返回第一次的结果，
  界面提示「这笔刚才已提交过（编号 XXX），没有重复记账」；**内容完全相同的另一张草稿 60 秒内再提交**也按重复处理，超过 60 秒视为新的一笔
- 修复：录入助手抽屉关掉再打开，提交过的草稿又能点「确认提交」。现在提交状态记在服务端，重开后显示「已提交 · 编号 XXX」，按钮不可点
- 修复：几个人同时新增流水 / 应收 / 付款单 / 工资批次 / 内部转账时，只有一笔成功、其余报「Unique constraint failed」。
  现在编号按序排队发放，同时提交的全部成功、编号连续不重复；万一失败，提示也是能看懂的中文，不再显示数据库原文
- 修复：新增流水不选业务类型时报数据库错误；现在按收支方向记为「其他收入 / 其他支出」（与导入一致）
- 修复（权限）：有数据范围的账号，原来能通过接口对别家公司的账户做**内部转账**、给别家公司的应收**登记回款**、
  把别家公司的发票 / 流水**互相关联**、在**批量修改流水**时夹带别家公司的流水、**导入流水 / 发票**到别家公司、查看别家公司的**月报**；现在一律拒绝
  （批量修改里只要有一笔越权，整批都不改）
- 变化：**登记回款时，收款账户必须属于该应收所在的公司**（界面上本来就只列本公司账户；以前直接调接口可以记到别家公司账户上，会让两家余额都错）
- 手机：录入助手输入框提示改为「点「发送」按钮发送，回车换行」（手机没有 Shift 键），软键盘回车只换行；电脑上仍是 Enter 发送、Shift+Enter 换行
- 手机：页面标题只在顶栏显示一次，页内重复的同名大标题不再显示（工资批次明细的批次信息照常显示）
- 数据库：新增 `code_sequences`（业务编号序列）、`assistant_drafts`（录入助手草稿与提交状态）、`assistant_submissions`（提交指纹）三张表，
  字段说明见 `docs/接口说明.md`；新增接口 `GET /api/fin/assistant/drafts`、`GET /api/fin/assistant/drafts/:id`、`POST /api/fin/assistant/drafts/:id/submit`，chat 返回的每张草稿多一个 `draftId`

**在钉钉、飞书、微信里用手机打开也能正常用了**

- 手机上的列表都改成**卡片**：一行一张卡，名称和状态在上、金额在右上角加粗，其余字段「标签：值」排开；空的字段不显示；
  编辑 / 作废 / @ 等按钮在卡片底部，按钮够大好点
- 手机上的筛选收进「筛选」按钮（底部弹出），关键字搜索框常驻；分页简化成「上一页 / 第几页 / 下一页」

- 驾驶舱 / 经营分析 / 资金预测：统计卡单列排，图表随屏幕自动缩放，手机上隐藏图例、减少刻度

## 2026-10-28（录入助手上线前修复）

**录入助手上线前的一轮修复（端到端测试发现）**

- 修复：草稿里的超大金额会丢分——`999999999999999.99` 会变成 `1000000000000000.00`；现在全程按字符串 + Decimal 处理，到 Decimal(18,2) 上限都精确
- 修复：`0x10`、`1e15` 这类写法会被当成金额（16、1000000000000000）；现在只认普通数字，其余进「不合法」提示
- 改进：全角数字金额（如「１２８０００」）自动转成半角，不再判为非法
- 修复：模型给 A 公司的草稿填了 B 公司的客户 / 项目时没有拦下；现在会移除该字段并提示「不属于所选公司」
- 修复：只能看 A 公司的人点名要 B 公司的草稿时，公司会被悄悄换成 A；现在保持「待补充」，让人自己选
- 改进：修改发票时只改了价税合计，会提示「不含税金额 + 税额 ≠ 价税合计，请一并修改」
- 修复（权限）：有数据范围的账号，原来能通过接口查看 / 修改 / 作废别家公司的账户、应收、发票、客户等记录，也能往别家公司新增；
  资金流水同样。现在详情、新增、修改、作废都按数据范围校验
- 修复（权限）：有数据范围的账号，列表带上别家公司的筛选（`company_id`）就能查到别家公司的应收、发票、流水、账户、工资、付款计划、月结记录，
  资金预测、异常清单、分析图表也一样；现在指定公司只能在自己的数据范围内生效，范围外查出来是空的
- 修复：录入助手里点名或 @ 一家自己无权访问的公司时，草稿的公司会填成那家公司；现在提示「不存在或无权访问」并保持待补充
- 改进：录入助手的操作日志只记白名单内的工具名，模型乱给的工具名不再原样写进日志，只记次数
- 修复：新增 / 修改资金流水时，接口不校验账户是否属于该公司、金额是否为正数、方向是否为收 / 支；现在会直接拒绝
- 修复：请求体不是合法 JSON 时接口返回 500，现在返回「请求参数不合法」

## 2026-10-28（v1.1）

**右侧录入助手：@ 一下记录，说一句话就把表单填好**

- 顶栏右侧新增「录入助手」图标，点开是右侧抽屉（默认 380px，可拖宽、可收起，记住上次状态；窄屏默认收起）
- 账户、资金流水、应收与收款、发票台账四个页面，每行多了一个「@」：点一下把这条记录引用进助手（应收页的客户名旁边也能 @ 客户）
- 在助手里说一句话，比如「录一笔应收：客户 12，金额 128000，月底到期」，助手生成一张**草稿卡**：
  - 缺的字段标红「待补充」，助手会反问；名称对上多个时让你在卡片上选
  - 「填入表单」：打开该页面原来的新增 / 编辑弹窗并预填，你核对后自己点保存
  - 「确认提交」：直接走原来的保存接口，权限、操作日志、账户余额重算和手工录入完全一样；有缺字段或没有对应的管理权限时按钮置灰
- **助手只生成草稿，不会直接写入任何数据**；金额必须大于 0、最多两位小数，日期按 YYYY-MM-DD，不合规的值不会进草稿
- 其余页面助手只做只读问答，不出草稿按钮
- 每次对话在「操作日志」记一条「助手对话」：页面、有没有出草稿、草稿类型、引用了哪些记录 id；不记对话原文和金额
- 需要「finance.view」权限（管理者 / 财务 / 经理 / 只读）；业务角色看不到入口
- 平台没配大模型时入口置灰并提示原因

**修复：以虎 One 上 AI 工具在没配 PORT 时调不通本系统接口**

- 工具内部调接口默认连 3000 端口，而后端默认监听 3010，现统一为 3010
